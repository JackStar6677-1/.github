# JackStar Community Health & Engineering Standards (.github)

This repository serves as the **global default community health configuration** for the [`JackStar6677-1`](https://github.com/JackStar6677-1) ecosystem on GitHub.

Any repository in this account that does not define its own community files automatically inherits:

* **[`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)**: Zero tolerance on harassment, insults, demanding entitlement, and toxicity. Outlines moderation protocols, thread locking, and account blocking.
* **[`CONTRIBUTING.md`](CONTRIBUTING.md)**: Strict issue-first workflow, high engineering standards, review criteria, and clean git discipline.
* **[`AGENTS.md`](AGENTS.md)**: Concrete standards for AI-assisted contributors, anti-hallucination policies, mandatory local verification, and anti-slop rules.
* **[Issue & PR Templates](.github/)**: Structured forms for reproducible bug reports, grounded feature proposals, and transparent AI disclosure.
